# Inbox

The quickest way to add something: one line per idea, in plain words, under **Inbox** below. Add a link if you
have one. Any editor works: Obsidian, GitHub's web editor, a phone.

The next AI session turns each line into a proper note in `plan/nodes/` (an idea, or a step with a test if it is
clear enough), links it to the pillar it belongs to, and removes the line here. Until then, `plan/MAP.md` lists
the lines under "Inbox".
