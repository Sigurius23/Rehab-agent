# Standing rules for agent sessions in CLAUDE.md

The standing rules every laptop prompt has repeated, written once so each session loads them itself: files that
feed the case fingerprints are not changed; no credentials on the workstation, ask before pushing; downloaded
data outside the repository, read with `python -I`; decisions recorded as dated amendments before any data is
opened; this map updated and `plan/build.py` run at the end of a session.

Written 2026-11-09 (`CLAUDE.md` at the repository root). Whether it works is for the test: a fresh session given
only a one-line task.
