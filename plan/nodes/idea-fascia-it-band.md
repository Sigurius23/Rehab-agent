# Whole-body fascia, starting with the Davis IT-band model

The strongest whole-body OpenSim fascia candidate in the research note: an anatomically informed iliotibial band added to a full-body model, with selected properties compared against cadaveric, MRI and dynamometer references and a running demonstration in one subject. It covers the IT band, not the whole fascial network, and one subject does not validate personal IT-band forces. Test it as a separate extension, checking it doesn't duplicate muscles or change their mechanics.
