# Predicted against measured DXA change over 8-12 weeks

With logged intake and training, the model's predicted change in lean and fat mass is compared with the change measured by DXA at the start and end of 8-12 weeks.

Write `expected` before the test runs: how close the predictions should be, for example relative to DXA's own repeatability, which should be checked first. The people tested should be fresh: not used to build or tune the model.
