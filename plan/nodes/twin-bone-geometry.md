# Torsion, anteversion and personalised bone geometry as inferred values with provenance and uncertainty

These stay in the person-specific model. What differs is how each value is obtained and how far it can be
trusted, not whether it belongs:
- camera and LiDAR observations can support estimates, including learned anatomy models trained on suitably
  licensed paired imaging data;
- estimates are labelled as inferred, with provenance, uncertainty and validation suited to each output;
- imaging-derived models or measurements can be imported when available, but routine radiation-bearing scans
  must not be required for healthy consumers;
- where the evidence is not enough, the parameter stays, with its value uncertain or unknown, never a generic value
  presented as measured.
