# Rehab Agent: an anatomically accurate movement twin a clinician can trust

anatomical accuracy as the first design priority. A research prototype, not a medical device (`README.md`).

This map holds the open work: goals, steps, tests, ideas and decisions. The documents hold the reasoning. How the
